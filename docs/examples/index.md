# Examples

Here you can find complete examples showing how to integrate Kanjou into various frameworks.

- **[React](./react.md)**: A standard React application showing full integration with Kanjou, custom rich components, and a custom `IntlProvider`.
- **[React + Vite Plugin](./react-vite-plugin.md)**: A React application configured with the `@kanjou/vite` plugin for seamless HMR and automatic type generation.
- **[Next.js](./nextjs.md)**: A Next.js App Router implementation showing Server/Client component integration.
